# Casos de uso del proyecto

En esta sección, voy a mostrar la lista de casos de uso que tengo del proyecto y de cada uno de ellos, voy a dejar una breve descripción para orientar a mi compañero, que los detallará mejor.

* **CU01: Iniciar sesión** -> Permitir el acceso a los usuarios en la aplicación con su correo de Turbine y contraseña.
* **CU02: Gestionar usuarios y roles** -> Permitir al administrador crear usuarios, asignándole unos clientes específicos.
* **CU03: Configurar y modificar el sistema** -> Permitir modificar configuraciones del sistema.
* **CU04: Gestionar clientes e importación** -> Gestionar datos fiscales y de contacto de los clientes y permitir la carga con archivos CSV.
* **CU05: Buscar y filtrar información** -> Dar herramientas para el filtrado y búsqueda de clientes y facturas.
* **CU06: Generar facturas** -> Crear facturas de manera única o de forma automática mensualmente en un formato PDF.
* **CU07: Consultar, modificar y descargar facturas** -> Consultar el historial de facturas, modificar sus datos o importaciones.
* **CU08: Enviar facturas y notificaciones** -> Enviar al cliente sus facturas y avisos, incluyendo datos de soporte.
* **CU09: Supervisar estado de pagos y cobros** -> Comprobar que una factura ha sido pagada y actualizar su estado.
* **CU10: Gestionar recordatorios de impagos** -> Enviar avisos automáticos de pago y detenerlos en cuanto se confirme.
* **CU11: Procesar baja de cliente** -> Comprobar que un cliente no tenga deudas pendientes antes de retirarse de la aplicación y aplicar un borrado lógico para conservar su historial.
* **CU12: Consultar tablero e informes de auditoría** -> Mostrar al administrador la evolución de las facturas y la actividad.
