# Informe Scrum — Proyecto Turbineh

## 1. Introducción

Para el desarrollo del proyecto Turbineh hemos utilizado una organización basada en Scrum, dividiendo el trabajo realizado en dos sprints.

El objetivo de trabajar de esta forma ha sido organizar las tareas, repartir responsabilidades entre los miembros del equipo, realizar un seguimiento del avance del proyecto y poder adaptarnos a los cambios que han ido apareciendo durante el análisis.

Uno de los aspectos más relevantes del proceso ha sido precisamente la adaptación a nueva información. Durante el Sprint 1 recibimos una ampliación de la entrevista con el cliente cuando una parte importante del análisis inicial ya estaba desarrollada. Esto hizo necesario revisar la planificación y trasladar al segundo sprint la actualización de parte de la documentación.

Para centralizar el trabajo y facilitar su seguimiento hemos utilizado un repositorio de GitHub junto con GitHub Project, donde se han almacenado los documentos y se ha actualizado el estado de las diferentes tareas.
